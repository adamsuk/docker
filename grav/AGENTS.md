# Grav

## Purpose
Lightweight CMS (Content Management System). Flat-file based, no database needed.

## Key Files
- `config/` - Grav application and content

## Access
- Port: 8011
- URL: http://server:8011

## Dependencies
- SWAG proxy network (reverse-proxied)

## Important Notes
- Pinned to version 1.7.33
- TZ set to America/New_York (inconsistency with other services)
- Watchtower label is commented out (manual updates)
- Uses `swag_proxy` network
- Flat-file CMS (no database required)
