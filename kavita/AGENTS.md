# Kavita

## Purpose
Fast, feature-rich ebook and comic server. Web-based reader for books and comics.

## Key Files
- `config/` - Kavita database and settings

## Access
- Port: 5000
- URL: http://server:5000

## Media Mounts
- `/media/big_boi/Books/Books` → `/books`
- `/media/big_boi/Books/Comics` → `/comics`

## Dependencies
- Ebook/comic files on big_boi drive

## Important Notes
- Watchtower enabled for auto-updates
- Supports EPUB, PDF, CBZ, CBR, and more
- Web-based reader with progress tracking
- SWAG proxy network is commented out (direct access only)
