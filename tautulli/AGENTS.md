# Tautulli

## Purpose
Plex monitoring and analytics. Tracks viewing history, statistics, and notifications.

## Key Files
- `config/` - Tautulli database and configuration

## Access
- Port: 8181
- URL: http://server:8181

## Dependencies
- Plex Media Server (reads Plex logs/database)

## Important Notes
- Read-only access to Plex (no modifications)
- Provides detailed viewing statistics
- Can send notifications for new additions
